## What is RoboForge?

RoboForge is a generative robotics settlement—not a chatbot, but a **living apparatus** that:

• Integrates multimodal sensors (raycasting, camera, microphone)
• Operates on **economic resource allocation** (tokens, compute, bandwidth)
• Generates responses as spatial-temporal interventions in physical space
• Scales atom-by-atom through marginal efficiency analysis
• Transmits presence wirelessly (inspired by Tesla's teleautomaton, 1898)

Like Tesla's remote-controlled boat at Madison Square Garden, RoboForge is:
  → RADIO-CONTROLLED by thought
  → SPATIALLY-AWARE via raycasting
  → ECONOMICALLY-EFFICIENT in resource use
  → WIRELESS-READY for future ESP32/Raspberry Pi embodiment

  1. [SENSE]    → Raycasting geometry | Camera RGB | Audio chunk

  5. [RESPOND]  → Output settlement action (text + future: servo control)

HOW TO USE ROBOFORGE (GETTING STARTED)
═══════════════════════════════════════════════════════════════════════════════

### Setup (same as before + new env var)

```bash
npm install
npm run dev
```

Create/update `.env.local`:

```
ANTHROPIC_API_KEY=your_api_key_here
ANTHROPIC_MODEL=claude-sonnet-4-20250514
SETTLEMENT_TOKEN_BUDGET=10000
SETTLEMENT_COMPUTE_BUDGET=100
```

### Run Settlement Viewer

Navigate to `/settlement` (route to be added).
Browser will request camera + microphone permissions.
Settlement loop initiates automatically.

### Monitor Economics

Dashboard displays:
  - Token spend/remaining
  - Sensor efficiencies (raycasting, camera, audio)
  - Marginal value trend
  - Latency per frame
  - Atom utilization %
